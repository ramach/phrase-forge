# Living Prototype Sprint 2.1 — Word Card + Word Role

Run: `pip install -r requirements.txt` then `streamlit run living_prototype.py`.

## Added
- Word Cards display grammatical roles, meaning, contextual examples, usage notes, and an expandable origin area.
- Curated editorial examples for ALREADY and AERIAL; other accepted words use existing Phrase Forge Lexicon metadata.
- When role metadata is inferred rather than verified, the UI labels it as a suggestion.
- Missing examples and etymologies are shown as missing, never invented.
- Source label for the displayed content.
- New Word Card tests.
