# Phrase Forge Changelog

## 0.9.0-beta — 2026-08-06

- Practice is now the default mode for new sessions.
- Each fresh session receives a curated random puzzle.
- New random puzzle avoids immediately repeating the current phrase.
- Daily mode remains deterministic and shared by all players for the date.
- Added prominent first-launch instructions and the `RAIN DELAY → ALREADY` example.
- Kept AI puzzle generation optional and locally validated.
- Added a configurable per-session AI-generation limit.
- Added a Beta Feedback tab with automatic diagnostic capture.
- Added downloadable diagnostic reports for testers.
- Added Admin beta diagnostics and feedback viewing.
- Preserved grading, roles, confidence, difficulty, hints, Explain My Answer, manual puzzles, and leaderboard behavior.

## Beta patch 0.9.1
- Fixed progressive hints resetting to Hint 1.
- Added guaranteed recognition and solver discovery for `claimer` with `inner calm`.

## 0.9.2-beta — 2026-08-06

- Added a spoiler-controlled **Show all solutions** control on the Play tab.
- The displayed list reuses the same validation rules as grading, hints, and difficulty.
- Added solution length, vowel/consonant start, and base score to the reveal table.
- Added a **Hide all solutions** action so players can return to normal play.
