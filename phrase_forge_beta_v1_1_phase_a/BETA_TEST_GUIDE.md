# Beta 1.0 Test Guide

Ask testers to try curated Practice, Daily, manual phrases, hints, Show all solutions, role identification, Explain My Answer, leaderboard submission, and Feedback.

Useful questions:
1. Was the goal clear within one minute?
2. Was the first puzzle enjoyable?
3. Were any accepted/rejected words surprising?
4. Did grammar explanations make sense?
5. Did hint progression help without spoiling too early?
6. Did difficulty feel plausible?
7. Would you play five more puzzles?

When reporting a word issue, include the phrase, proposed solution, lexicon profile, and Explain My Answer output.
