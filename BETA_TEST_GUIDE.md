# Phrase Forge Beta Test Guide

Please test both the game and the learning experience.

1. Was the goal clear within the first minute?
2. Was the first puzzle enjoyable?
3. Were the hints useful without revealing too much?
4. Did the grammar explanation teach you something?
5. Were any valid words rejected or invalid words accepted?
6. Did difficulty and confidence feel reasonable?
7. Would you play another five puzzles?

Use the **Feedback** tab. It automatically includes the current puzzle, settings, submitted answers, grading results, difficulty, grammar diagnostics, and hint history.
