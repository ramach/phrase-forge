# Phrase Forge Beta 1.0 Notes

Beta 1.0 is the first architecture-focused beta. It preserves the tested 0.9.x gameplay while adding the Phrase Forge Lexicon, indexed solver, and persistent PostgreSQL option.

Recommended beta configuration:
- Practice mode default
- Standard lexicon profile
- AI optional with a low per-session generation limit
- PostgreSQL `DATABASE_URL` configured for shared leaderboard/feedback

Please report rejected legitimate words, accepted names/acronyms, incorrect grammar inference, unclear onboarding, hint problems, and difficulty mismatches.
